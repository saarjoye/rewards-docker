# 测试

自动测试只能使用合成账号、Cookie、Session、页面、响应和 SQLite 临时目录，不调用 Microsoft Rewards 或其他外部 API。

最低覆盖范围：

- 三个认证槽隔离和三层登录验证。
- 字段证据状态、来源优先级和旧快照拒绝。
- 标准任务注册表、未知任务保留和任务数量汇总。
- mutation 幂等、待复核只读续跑和统一重试分类。
- 本地日期午夜、账号选择和失败状态聚合。
- 搜索阶段超时、取消和部分进度保留。
- 加密、原子 Session 写入、日志 canary 和备份恢复。
- Fastify API 与 React UI 的加载、空、失败、部分完成和人工介入状态。

真实验收分四阶段：离线测试、三账号只读、单账号受控 mutation、三账号连续三个本地业务日运行。后两阶段需要单独授权，并且旧任务执行器必须暂停。
