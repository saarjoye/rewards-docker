# Microsoft Rewards 全自动化架构平台 (v6.0 标准版)

> **核心宗旨**：纯账号密码驱动 · 官方真实数据驱动 · 多端真实交互击穿 · 绝不造假虚标

---

## 🌟 项目愿景与技术突破

本工程依据 `REWARDS_NEW_ARCHITECTURE_DESIGN.md` 规范从零打造，彻底清算旧版实现三大痛点：
1. **告别手动凭据门槛**：不再需要抓包提取 Cookie 或手动复制 OAuth Code。用户只需提供微软邮箱与密码，底层自适应状态机自动完成 KMSI 穿透、OAuth 授权码实时截获换取移动端 Token，并通过 Bing SSO 自愈生成必应 `_U` 与 `WLS` 凭据。
2. **拒绝任务虚报与积分造假**：所有任务进度与今日积分一律对标微软官方 `/earn` 与 `/dashboard` 权威页面，绝不使用本地卡片虚增；不可执行任务（如 Edge 30分钟硬件遥测、默认引擎配置、Xbox会员购买）明确标记为跳过，绝不欺骗用户。
3. **多端仿真与风控守护**：结合拟人化打字延迟、贝塞尔曲线鼠标轨迹、随机驻留与停滞熔断守护（`SearchStagnationGuard`），保障账号长期稳定运行。

## 🚀 快速启动

### 方式一：本地 Node.js 运行

1. **环境要求**：Node.js >= 20 (推荐 Node.js 24)
2. **安装依赖**：
   ```bash
   npm install
   ```
3. **启动服务**：
   ```bash
   npm start
   ```
4. 打开浏览器访问控制台：`http://localhost:5308`。

### 方式二：Docker Compose 一键部署

```bash
docker compose up -d
```
控制台端口为 `5308`，运行数据持久化至宿主机目录（如 `/docker/home/rewards-v3` 或 `./data`）。

## ⚙️ 账号配置方式

1. **WebUI 可视化向导**：
   - 打开控制台，点击右上角「+ 添加账号」；
   - 填写微软邮箱、密码及可选代理（HTTP/SOCKS5）；
   - 点击保存，系统立即自动执行后台无头登录与双通道凭据收割。
2. **本地 `.env` 凭据一键载入**：
   - 支持在项目根目录创建 `.env` 文件（参考 `.env.example`）：
     ```env
     MS_USER=your_email@outlook.com
     MS_PASS=your_password
     ```
   - 在 Web 控制台点击「📁 载入本地配置」，系统自动发现并导入。
